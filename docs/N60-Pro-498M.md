# N60 Pro 498MiB NAND（CWRT）

在 Actions 中选择 **N60-Pro-498M**，手动运行；TEST 仅验证配置，关闭 TEST 才编译固件。沿用本仓库的插件、MT7986 闭源无线及硬件加速配置。

## 闪存布局

基于 Yuzhii0718/immortalwrt-mt798x-6.6-padavanonly 的 openwrt-24.10-6.6 分支。
适配假设：512MiB SPI NAND，128KiB 擦除块，2048 字节页；U-Boot 使用与该源码 N60 Pro 相容的 NMBM 和 UBI kernel/rootfs 启动布局。

- bl2、u-boot-env、factory、fip 的位置保持源码原值。
- UBI 起点：0x00580000（5.5MiB）。
- UBI 长度：0x1f280000（498,5MB（498.5MiB））。
- UBI 终点：0x1f800000（504MiB）。
- 最后 8MiB 留给 NMBM，符合当前设备树的 64 个保留块上限及 128KiB 块大小。
- 498,5MB（498.5MiB） 是分区长度，文件系统可用空间还要扣除 UBI 开销及坏块预留。

现有 NMBM 表会影响实际映射；若芯片几何参数或 U-Boot 的 NMBM 布局不同，应重新核对分区，不能直接按此数值使用。此适配不会修改或刷写 U-Boot。

## 镜像

- **factory.ubi**：含 kernel 和 rootfs 卷，供支持此 UBI 布局的 U-Boot 固件刷写入口使用。它不是整片 NAND 备份，不含 BL2、FIP 或无线校准数据。
- **sysupgrade.bin**：CWRT 后续升级使用。
- 不进行从旧 OWRT 在线升级的兼容处理。

设备 profile 和 compatible 沿用 netcore_n60-pro / netcore,n60-pro；专用工作流才应用补丁，普通 MT7986 编译保持原版容量。镜像基本文件名仍含 netcore_n60-pro，通过 N60-Pro-498M 发布标签和系统型号中的 498M 区分，仅用于扩容机。
